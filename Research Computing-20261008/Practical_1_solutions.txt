Basic Linux usage
=================

1) whoami, id

2) ls (or ls $HOME)

3) pwd
  In my case, I get /home/raid/pmb39. Yours may differ.

4) Use "ls -a" or "ls -al".

5) Hopefully, you own your own files (3rd column of "ls -al")

6) The root user should own all files in /usr/bin/

7) Use 'top'

8) mkdir Linux_exercises

9) cp /usr/bin/gcc ./Linux_exercises

10) mv /usr/bin/gcc ./Linux_exercises
should give "Permission denied" because you do not own the file
/usr/bin/gcc

11) file /usr/bin/gcc
/usr/bin/gcc: symbolic link to gcc-9

12) file Linux_exercises/gcc
gcc: broken symbolic link to gcc-9

13) cp -L /usr/bin/gcc ./Linux_exercises

linked, interpreter /lib64/ld-linux-x86-64.so.2,

14) find -size +1M
